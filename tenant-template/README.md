# قالب موقع الجهة

الكود المشترك الذي يعمل عليه موقع كل جهة إعلامية، يُنشر كمشروع Vercel مستقل لكل جهة (يُنشئه
المصنع تلقائيًا في `../factory/`، أو يُنشر يدويًا بنفس الطريقة).

للتعليمات الكاملة من الصفر حتى النشر، راجع **`../DEPLOYMENT_GUIDE.md`**. هذا الملف يغطي فقط ما
يخص هذا المجلد تحديدًا.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط اتصال Postgres — نفس الرابط المشترك بين كل الجهات على خادم المصنع. |
| `DB_SCHEMA` | مخطط (schema) هذه الجهة تحديدًا على ذلك الخادم، مثل `tenant_42`. هذا ما يعزل بياناتها — انظر `lib/db.js`. |

لا شيء غيرهما — بيانات الأدمن الرئيسي تعيش في جدول `main_admins` (تُنشأ عبر معالج المصنع أو
يدويًا، انظر تعليقات migration 002).

## قاعدة البيانات

شغّل ملفات الهجرة الثلاثة بالترتيب ضد مخطط هذه الجهة:
```
migrations/001_base_schema.sql
migrations/002_share_platforms_and_site_settings.sql
migrations/003_logo_storage.sql
```

## بنية الكود

- `index.html` / `admin.html` — الواجهة العامة ولوحة الإدارة
- `api/[...path].js` — كل منطق الخادم (مصادقة، حملات، تغريدات، تحليلات، تقارير)
- `lib/db.js` — طبقة الوصول لقاعدة البيانات: باني استعلامات Postgres مرن (`db.from('table')
  .select().eq()...`)، مُختبَر بالكامل في `lib/db.test.js` (`npm test`)
- `sw.js` — Service Worker للإشعارات
- `migrations/` — مخطط قاعدة البيانات، بترتيب التطبيق

## رفع الشعار

الشعار الصغير المرفوع يُخزَّن مباشرة في `site_settings.logo_data_base64` (migration 003)
ويُعرض عبر `GET /api/logo`. رابط صورة خارجي في `site_settings.logo_url` يعمل أيضًا كبديل.
